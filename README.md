# VolumetricTools-Fab

This is a FREE Unreal Engine plugin, available on Fab, that adds Volume asset manipulation in the editor.

The plugin can:
* Converts **Static Vector Field assets** into **Volume Texture assets**, preserving dimensions and voxel data.
* Convert **Sparse Volume Texture assets** into (dense) **Volune Texture assets**, with same size or with downsizing.
* Apply any mathematical operation on texture values, creating a new Texture or modifying source texture in-place.
